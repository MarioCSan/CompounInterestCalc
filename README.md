# Compound Interest Calculator 

An interactive compound interest calculator built with React, styled in a bold vaporwave aesthetic inspired by 1980s neon, synthwave gradients, and retro visuals.

## ✨ Features
Accurate compound interest calculation with:
Initial investment
Recurring contributions
Customizable interest rate and frequency
Animated bar and pie charts (Recharts)
Inspired by the <i>Miami Vice</i> color palette: electric purples, cyan, and pastel pink
Clean, modular React code (with Hooks)

## 🚀 Tech Stack
- React
- Recharts
